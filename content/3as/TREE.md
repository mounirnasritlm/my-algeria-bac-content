# 3AS Physical Content Tree

This is the real browsable folder structure for the Algerian 3AS AI Teacher content.

The `branches/` tree provides branch → subject navigation without duplicating shared resources. The `subjects/` tree is canonical and contains the actual resource folders.

See the folder names directly in GitHub for:

- curriculum_programme
- courses_lessons
- summaries
- books
- teacher_books
- exercises / corrections
- devoirs / first_term / second_term / third_term / corrections
- tests / first_term / second_term / third_term / corrections
- exams / first_term / second_term / third_term / corrections
- bac / blanc / official / historical / corrections
- source_metadata
- curriculum_mapping

Original raw PDFs and extraction outputs remain preserved in `content/sources/`. Canonical subject folders are populated only after manual validation.
