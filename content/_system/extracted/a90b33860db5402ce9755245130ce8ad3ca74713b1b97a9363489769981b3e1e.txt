4) La question de synthèse : (donnez votre avis en deux ou trois 
lignes ?)  
 Pour répondre à cette question il faut suivre 4 étapes : 
 Utiliser un verbe ou une expression d’opinion. 
 Exprimer un rapport logique (cause/conséquence/but). 
 Donner une information personnelle ou bien tirer une 
idée du texte et la reformuler. 
 Respecter le nombre de ligne demandé.  
5) Le renvoi des pronoms :  
 Les pronoms adverbiaux :  
 « Y » : remplace un lieu.  
 « En » remplace un COD. 
 Les pronoms COD :  
 « Le » : remplace un nom masculin singulier. 
 « La » : remplace un nom féminin singulier. 
 « L’ » : remplace un nom singulier masculin ou féminin. 
 « Les » : remplace un nom pluriel.

 « lui » : remplace un COI singulier. 
 « leur » : remplace un COI pluriel.

1.  les différentes parties de l’appel : 
 La partie expositive : le constat négatif (le problème).  
 La partie argumentative : l’auteur donne des arguments pour 
convaincre le récepteur qu’il y a un problème qui doit être 
résolu.  (les verbes de modalités)  
 La partie exhortative : l’auteur lance l’appel aux destinataires 
dans le but de les inciter pour un éventuel changement. (les 
verbes performatifs) 
2.  les verbes de modalités :  
 Pouvoir : la possibilité 
 Ex : quand il y a du bruit, je ne peux pas travailler. 
 Falloir : la nécessité  
 Ex : il faut que vous veniez demain.  
 Devoir : l’obligation  
 Ex : tu dois obéir tes parents. 
 Vouloir : la volonté  
 Ex : je veux devenir un médecin en chirurgie dentaire.  
 Souhaiter : le souhait  
 Ex : je souhaite avoir une bonne note au baccalauréat. 
 Refuser : le refus  
 Ex : je refuserai votre invitation car je suis occupé.

4. Le mode impératif :  
 est un mode qui exprime l’ordre. 
 Il n’y a que trois personnes à l’impératif : (je/nous/vous). 
 Ce mode est caractérisé par l’absence du sujet. 
     Exemples :  
 Donne-lui une chance ! / donnons / donnez       (donner)  
 Pense à ton bac !  / pensons / pensez                 (penser)  
Penses-y ! (en – y) 
 Finis ton travail ! / finissons / finissez                  (finir)  
 Prends tes médicaments ! / prenons / prenez      (prendre) 
5. L’expression du but :  
 On exprime le rapport logique de but en mettent en 
relation deux actions : l’une réelle et l’autre éventuelle.  
 Les connecteurs : 
 Pour : + un nom / verbe à l’infinitif. 
 Afin de ; dans le but de ; en vue de ; de crainte de ; de peur de ; 
dans l’intention de ... : + un verbe à l’infinitif. 
 Pour que ; afin que ; de sorte que ; de manière à ce que ; de 
façon à ce que ; de peur que ; de crainte que… : + le subjonctif.
